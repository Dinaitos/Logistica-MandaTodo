# Logística MandáTodo

Sistema web de gestión y seguimiento de envíos para el Caso 7 de Práctica Profesionalizante I. El proyecto aborda la carga y administración de pedidos, la validación y geolocalización de direcciones y el trabajo de operadores y choferes.

Este repositorio presenta por etapas una copia de portfolio del trabajo colaborativo del Grupo 9. La publicación conserva los commits y la autoría originales; las PRs nuevas documentan la migración a la cuenta Dinaitos y enlazan los cambios de origen.

## Tecnologías

- Frontend: React y Vite.
- Backend: Node.js y Express.
- Datos: MySQL.
- Entorno local: Docker Compose.

## Estado

Es un MVP académico, no un sistema listo para operar en producción. La importación histórica está en curso y sus etapas, fechas y referencias se registran en [docs/importacion-historica.md](docs/importacion-historica.md).
